Décris ton voyage normalement. L’app transforme ta demande en brief complet pour ChatGPT, puis peut importer sa réponse pour construire automatiquement le voyage et ses spots.

1 · Décris ce que tu veux

3 · Importe la réponse de ChatGPT

Demande à ChatGPT de répondre avec le JSON prévu par le brief, puis colle-le ici. L’app créera le voyage et ses spots automatiquement.

En attente d’une réponse.

Mode IA direct — architecture prête

Pour supprimer complètement le copier-coller, cette app peut être reliée ensuite à un backend OpenAI. La clé API ne doit pas être placée directement dans le HTML public. Le backend reçoit ton brief, interroge OpenAI, valide le JSON puis renvoie le voyage à l’app.
